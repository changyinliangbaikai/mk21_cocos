## 侧边栏接入验收

`tools/templates/douyin-sidebar.js` 在打包后的 `game.js` 第一行同步加载，先监听 `tt.onShow`，再读取冷启动信息和检测 `tt.checkScene`。只有宿主支持时才在营地显示入口；用户主动点击后调用 `tt.navigateToScene`。热启动使用最新参数替换旧来源，失败显示可重试提示。

首版不配置奖励，不改变养成数值。模拟器已跑通：营地入口 → 引导弹窗 → 平台侧边栏 → 点击本游戏 → 恢复原阶段 → 再次打开引导显示“已从侧边栏返回”。新候选仍需真机复核这段新增流程。

未上线游戏可能不出现在真机侧边栏；可用 IDE 侧边栏模拟和场景 `021036` 扫码预览验证，完整真机链路按平台测试设备指引操作。不要因为真机没有未上线入口就误判为游戏代码失败。[侧边栏技术指南](https://partner.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/open-ability/Introduction-for-tech)
