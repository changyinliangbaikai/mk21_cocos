# 超力英雄 · 微信发布文案

更新：2026-09-15。对应微信 AppID `wx130a8544c32afd2c`，已上传代码版本 `0.7.1`。以下描述基于当前已实现的 v0.7 玩法。

## 各主要场景描述

游戏主界面风格：本游戏采用竖屏 2D 卡通插画风格，以明亮的蓝绿、暖黄和木色营造轻松活泼的英雄营地。角色造型圆润，动作夸张，界面使用木质牌匾、圆角卡片和醒目的按钮。营地主界面展示出战英雄、养成入口及开始或继续防守按钮；战斗界面由三条纵向路线、英雄布阵区和底部营地防线组成，并集中展示波次、基地耐久、能量和技能。英雄养成界面展示角色、等级、属性、外观形态及动作预览；波次结束后以三张强化卡供玩家选择；结算界面汇总本局防守结果与成长收益。

| 主要场景 | 画面与操作内容 |
| --- | --- |
| 营地主界面 | 明亮的卡通营地背景，显示当前出战英雄及养成入口，可开始新局、继续防守或调整阵容。 |
| 三路防守战斗 | 怪物沿三条路线接近营地，英雄在固定位置自动攻击；玩家通过底部英雄卡召唤，并进行换位、合成或释放技能。 |
| 英雄养成 | 集中展示英雄形象、永久等级与属性，提供升级、外观形态切换和待机、攻击、胜利动作预览。 |
| 出战编队 | 展示已选择和可选择的英雄，允许增减英雄种类、调整顺序并保存新局阵容。 |
| 波间强化选卡 | 同屏展示三张不同效果的卡牌，玩家阅读效果并选取一张，用于强化英雄、形成联动或获得技能。 |
| 战斗结算 | 显示本局防守结果、完成波次与成长收益，可返回营地养成英雄并再次挑战。 |

## 整体玩法设计

具体玩法为：玩家先在营地选择 1～4 类已解锁英雄组成出战阵容，进入由 20 波敌人组成的三路塔防关卡。开局获得 120 点能量，每次消耗 40 点能量召唤一名一星英雄，击败怪物可继续获得能量。场上设有 9 个战斗位置和 3 个待部署位置，英雄在攻击范围内自动作战，玩家可随时调整站位；两个同名、同星英雄可以合成为更高星级，最高三星。本局首次合成某类三星英雄可解锁对应主动技能，玩家最多同时装备两个技能并择机释放。第 1～19 波完成后从三张强化卡中选择一张，构建英雄强化和技能联动，随后自动进入下一波；第 5、10、15 波出现小 Boss，第 20 波挑战大 Boss。基地耐久归零时可按本局规则使用有限次数的救场或免费复活，最终以守住全部波次或挑战失败结束。完成波次获得的训练经验可用于局外英雄升级与形态解锁，英雄养成长期保留；游戏支持倍速、暂停和本地存档，方便分段继续挑战。
