## 可复用构建

依赖：Node.js（满足锁定版本 sharp 的要求）、`npm ci`、Cocos Creator 3.8.8、包含 `libmp3lame` 的 FFmpeg。

当前根目录 `release.local.json` 已配置微信 AppID，文件已加入 Git 忽略。运行 `npm run build:wechat`；`npm run build:minigames` 及不指定平台的发布脚本也仅构建微信。首次配置其他机器时，可复制 `docs/release/release.local.example.json` 并填写 `wechatAppId`；也可以使用 `WECHAT_APP_ID` 环境变量。脚本不会请求或使用 AppSecret。

```bash
npm ci
npm run verify
npm run typecheck:cocos
npm run build:wechat
```

尚无 AppID 时，仅用于本地调查：

```bash
npm run build:wechat -- --test-appid
```

默认路径为 `/Applications/Cocos/Creator/3.8.8/CocosCreator.app`，可通过 `COCOS_CREATOR_APP` 或 `COCOS_CREATOR` 指定安装位置，FFmpeg 可通过 `FFMPEG` 指定。构建不自动上传。每次构建生成独立时间戳目录，禁止 GUI 与 CLI 同时导入同一副本。

压缩策略：PNG 调色板 quality 90、不缩放、保留 UUID 和裁剪框；背景音乐从 OGG 转为 112 kbps MP3 并移除副本中的重复 OGG；WAV 音效转换为 MP3 VBR quality 4。中文字体、字体许可、关卡配置和全部游戏内容保留。主工程仍使用原有资源。
