## 最新调整：R1.0.4 / C-030

用户发现所有英雄集火最靠前的小怪，导致弹道浪费，并反馈厨师召唤物很快消失、鞋柜攻击混用爆米花。原排序的首项确实是敌人纵坐标；原表现代码也把没有RH前缀的所有友方弹道/命中映射为FX-RH02。

- 选敌顺序改为：有效射程内，距离任一存活英雄120设计像素以内的近战威胁 → Boss/小Boss → 距离当前攻击者最近的敌人。各档按真实二维距离、单位序号稳定排序；近战50%纵向射程和S1多目标不重复仍保持。
- 普攻和召唤追加攻击在选敌时估计其他英雄前摇、已发射弹道的直接伤害，计入防御、远程抗性、现有/待触发护盾。已有伤害足以击败目标时选择其它目标，或短暂等待在途攻击结算；Boss生命足够时允许多人集火。只预留主要目标，不把不确定的范围溅射或未释放技能预算成必然伤害。
- 普攻前摇结束时重新核验目标；友方弹道的目标提前死亡后，按同一优先级从弹道当前位置改道一次，保留原伤害与范围。敌方弹道不获得该能力。预留量从现有对局状态计算，不另设跨存档缓存；可选retargeted字段兼容旧弹道。
- 玉米炮维持次数型规则：不可被选为肉盾、免疫受击，追加2～6发，每0.65秒一发，打完收回；无敌人等待2秒收回。未发现它被怪物攻击后扣血的现有路径；原一级1.3秒打完且未播放发射/退出动画、又绘有血条，会造成“一碰就消失”的观感。现在显示“余弹”，播放发射和收回，最后一发独立完成命中；未改成可被击杀的耐久召唤物。
- 鞋柜仍可受击，按自己的生命/时限退场。其弹道使用FX-RH04拖鞋、紫色命中；玉米炮使用FX-RH02大玉米弹及爆破，沙包使用RH06效果。未知来源不再默认变成爆米花。全部复用已确认素材，没有重生成PNG。

222项逻辑测试和32文件Cocos真实声明检查通过，包含12项新的选敌、预估伤害、转向、召唤寿命、旧档与素材映射回归。18组烟测正常结束且全部中途读档恢复；第1/2关×4种选卡策略×16种子共128局均结束，首次能量抽卡均值11.4～12.71战斗秒。这些合成策略不等同于实际玩家胜率，也不证明手机性能。

证据目录：`artifacts/r1/targeting-c030/`。新增隔离浏览器场景 `?qa=1&qaScene=summons|targeting`，只使用内存存档。C-029的关间/波间数值保持；新版选敌和素材修正用于更新后继续的对局。旧对局仍保留自身难度快照、英雄、卡牌与进度。未上传微信或提交Git。

- 最终Web构建：`artifacts/cocos/2026-09-25T02-28-22-667Z-web-mobile.json`，源文件哈希未变化。实页四英雄分别命中同侧四个小怪；鞋柜弹道为FX-RH04、54设计像素，受击后剩62生命仍继续发射，使用发射/受击姿态。
- 玉米炮实页显示“余弹6”、无血条；按已确认的6发配置运行后出现summon-spent且末发继续命中。首次检查发现空文字初始化配合SHRINK导致实际字号为负、文字不可见，已改成非空初值与固定字号，重建后目视可见。发射/退出沿固定战斗时钟播放。

## 上轮调整：R1.0.3 / C-029

用户反馈第二关未到第4波即全灭。实际页面记录为第3波、45.78战斗秒、投放74只小怪、击杀39只，3名已上阵英雄均阵亡。原关号倍率每关复利6%，但首关奖励最多5张碎片，不足10张升级；原0.5秒投放叠加早期单目标伤害，过于依赖抽到并选中S1多目标升级。按反馈进行了首轮调校，新的真实试玩体验仍需继续验证。

- 关号倍率改为 `1 + 0.025 × (关号−1)`；困难/超困难生命和攻击仍乘1.2/1.5。
- 第1～5波生命/攻击倍率依次为0.72、0.80、0.88、0.96、1.04；之后每波加0.025，到第15波1.29。移速和攻速保持原定义。
- 普通关投放间隔第1～4波为0.85/0.80/0.75/0.70战斗秒，之后0.70；困难为0.90/0.85/0.80/0.75，超困难为1.05/1.00/0.95/0.90。挑战关用更疏的投放承接额外属性、特性和Boss压力。仍是15波、每波30小怪；全部投出后最多5秒进入下一波，清场可提前。
- 每小怪9能量、100能量抽卡、前5关无远程小怪、Boss/复活/奖励规则保持。首关至第二关不预设任何永久升级。
- 新对局保存难度快照，包含关卡倍率、15波倍率与投放节奏；无快照的R1.0～R1.0.2对局按旧曲线继续。恢复对局不会重掷出生计划或候选、不会清空存档。全局技能伤害使用同一份快照，保持与敌人的比例。
