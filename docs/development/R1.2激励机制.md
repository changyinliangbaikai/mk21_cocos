## R1.2.1 · C-035 暂停与结束对局

用户反馈开局/局内抽卡不能点击暂停，暂停菜单缺少结束本局。修复透明抽卡/瞄准拦截层的事件层级，将暂停点击区域放到其上方；其它底层操作仍被拦截。选槽、抽卡、瞄准都可以暂停，继续后恢复原状态，不重抽卡牌。

暂停菜单新增“结束本局 → 确认结束”。取消保留暂停与选卡进度；确认后原子保存 `run=null`、`settlement=null`，不执行阵亡结算、不领取碎片或战斗储备，永久养成记录保留。存储失败时原对局保持暂停，重试成功后才退出战斗并回营地；刷新后不能恢复已经结束的旧局。原“保存并返回营地”继续保留对局。

381项测试通过（新增5项暂停/退出回归），34文件Cocos声明检查通过，字体731字符无缺失。本补丁沿用成长规则版本R1.2.0，已有存档/旧对局无需重新开始即可使用新的暂停菜单。浏览器与构建证据在 `artifacts/r1/c035/verification.json`。

2026-09-30 微信上传前模拟器检查发现两处宿主兼容问题并修复：字体 CSS FontFaceSet 校验仅用于真实浏览器；微信不存在的存档键返回空字符串，由新增 `HostStorage` 在确认键不存在后归一化为 `null`。已有空值或损坏数据仍拒绝覆盖，迁移保留原始旧档，多窗口写入保护继续生效。字体重试清除历史错误，启动失败记录具体原因。新增6项字体/宿主存档回归后共387项测试、35文件Cocos声明检查通过。平台上传结果见 [微信发布推进](../release/小游戏发布推进.md)。

## 已实现的游戏循环

- 蓝/紫/金分别选一个培养对象；另选已解锁队长。第一轮开局抽卡固定一张队长候选，其余规则不变。
- 重复胜利同品质最多2个基础专属位定向；首通专属全定向；新手首次蓝色永久升级前蓝片全定向。满级在同品质内回退，通用片不转品质。
- 首通5/15关：5紫；8关：烟火龙仔5金；10关可选6金4紫或10紫；20关可选10金或10紫。普通/困难仍5片，超困难仍10片。
- 实际完整清除前5/10波及Boss认证储备。最终阵亡普通/困难1/2片，超困难2/4片；复活中不领取，胜利不追加储备，主动放弃0片。
- 永久Lv3开放每英雄A/B专精；局外免费切换，下局生效。20种专精全部接入真实伤害、几何、治疗、弹射、召唤或CD判定，中央主动技能未变。
- 6条新手成长记录、4条战术成就。通过实际施法编号、最终死亡、拉拢来源、受控命中、CD返还和承伤统计；动画不能触发成就。
- 20关后开放8阶、每阶3种固定公开契约。每波30小怪，其中9只特性怪；15波、450小怪、5个Boss。每阶首次胜利全定向，10片上限，三契约共用首胜资格，不套用剧情终章金包。
- Lv6/10/15/20为名牌、出手冠形徽记、精通与毕业称号，无额外战斗数值。

## 界面与资产

营地新增培养卡、成长实绩与远征入口；英雄详情可设置培养目标/队长并进入专精；章节页面可预选养金/养紫；结算展示真实奖励、数量上限、升级前后进度与下一步。

当主目标本局未获碎片时，结算临时展示实际获得成长的可用英雄，优先可升级者；不自动更改玩家的培养计划。三选一卡高、位置、无暗色遮罩保持。检查点提示延后至选卡/救场结束，显示0.9真实秒；暂停冻结。

新增页面复用现有图集、字体、原生Graphics和Label，未新增常驻位图；20个专精用原技能图标、A/B色卡和取舍文案组合区分。厨师回响、木桩摧毁定身、光束/冰雾范围、齐射和护盾反馈均对应真实判定。重建2份字体子集，730字符无缺字。

## 存档与接口

- `domain/r1/incentives.ts`：版本化成长配置、专精定义、契约、目标与战斗统计。
- `rewards.ts`：旧奖励算法保留；新奖励使用开局快照与一次原子结算。
- `session.ts`：计划/队长/路线/专精事务，保存失败保留待重试结果，多窗口冲突保护。
- `combat.ts`：真实专精效果、独立来源增益、施法与命中统计。

在原schema 1中加入 `profile.incentive.version=1` 和可选 `run.incentive`，缺失命名空间才执行迁移；未来或损坏数据拒绝覆盖。首次迁移在 `incentiveBackup` 保留原始序列化存档。已通关关卡按已领首通处理，不补发章节奖励；旧进行中对局没有成长快照，继续原规则。后续新局保存队长、培养目标、专精、路线与模式快照。

结算在同一次写入里保存英雄解锁、碎片库存、首通标记、远征进度、成就与账本。复活、后台返回、重新加载或重试写入不能重复领取或重掷。
