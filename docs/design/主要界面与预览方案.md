# 主要界面与预览方案

界面方案V2，对应玩法v0.5。用户要求展开局外解锁、养成和编队，并确认永久等级提升数值、解锁形态和动画。上一版将这些内容挤在S02内，现拆分；所有图片仍待确认，本会话不编码。

## 1. 当前界面数量

6个主界面＋7个关键浮层。英雄详情再展示一个锁定状态，共14种代表画面：新增局外6张，加沿用战斗/通用8张。历史S01大厅、S02合并图鉴被替代，但文件保留。界面层级数量与静态预览张数不同，不能把每个状态都算作一个独立页面。

## 2. 局外与局内的成长分工

局外养成永久保留等级、训练经验、已解锁形态及所选外观。界面用Lv数字；升级页显示前后加成、成本、解锁内容。查看形态和试播动作不扣经验，明确点击升级才提交消费；穿戴是独立操作。已拥有外观可选回，等级数值不回退。

局内依然同名同星2合1，最高三星，每种英雄首次三星解锁对应K系玩家技能。局外Lv3不等于局内三星。卡牌、能量、合成星级、技能库及救场次数新局重置。

创建新局时锁定队伍英雄种类、等级、所选形态；已有局继续原快照。营地存在旧局时显示“继续防守”和旧波次，养成/编队调整旁说明“新局生效”。免费复活后的布阵仍在S03完成。详细经济与等级建议见[局外养成方案](局外英雄养成与界面方案.md)。

细化的按钮允许状态、取消和事务规则现已补齐于[界面状态与操作契约](界面状态与操作契约.md)。下列状态不要求在开工前全部重生成图片。

## 3. 未单独生成的状态

N03还需覆盖经验不足、满级、升级成功、形态解锁成功、穿戴已拥有外观与动画播放。N04还需明确空队伍不可开局、未拥有不可加入、未保存退出提示。S03复用初始部署、战间部署、瞄准、冷静波、满员和免费复活后布阵状态。

S04胜负共用结构。N06展示解锁时可能有进行中的局，结果说明可在波间关闭；去局外前应保存并明确返回营地，不得静默终止旧局。新英雄只对新局的可召唤池生效。

D03第20波隐藏不存在的下一波预支；D04广告待决、主动取消、技术失败等沿用系统规则。静态图不代表全部界面状态已定稿或实现。

## 4. 视觉与当前限制

圆润玩具卡通、米白面板、湖蓝操作、黄色能量、蓝色书本训练经验、紫色技能。形态保持每个英雄身份和攻击语义，动作不改变判定。战斗与局外页面分开；永久形态与局内星级不做成36套独立角色。

各图为独立进度示例，不是同一存档连续截图。N03形态/动作按钮是静态示意，实际动画尚未制作。当前N02/N04未完整展示永久Lv和所选外观小标，N03待机小图沿用初始服装；这些应在后续原生细化时补齐。旧S04还需训练经验汇总与永久成长保留文案，旧D05的背景需换为N05。具体记录见各图metadata。

图中等级上限、成本、加成和外形门槛为设计建议；用户已确认成长类型，未逐项确认这些数字。所有预览in_review，按编号逐张决策。当前4位英雄最多带4位，缺少足够的阵容替换选择；未来至少6选4作为内容扩展另行讨论，不在图中虚构已完成的英雄。
