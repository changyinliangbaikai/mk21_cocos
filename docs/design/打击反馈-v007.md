本轮复用已导入的玉米、爆米花、拳套、弹簧、音波、拖鞋、烟雾和角色纹理，用 Cocos Graphics 叠加轮廓、速度线、音符和局部爆点。没有生成或导入新美术，没有更改伤害、射程、击退、奖励或随机流。

## 时钟与事件

TextureEffects.update(realDt, combatTimeScale) 接收已含 1×/2× 的有效倍率。战斗 tick 已由 Session 减速，这里只在该 tick 与下一 tick 之间补间，绝不二次缩放；UI 时钟保持真实时间。0.7 的 summon / move 是慢动作，音效继续消费真实事件；0.5 / 0.6 旧局仍按暂停处理。

SpriteActor.hit(eventSeconds, eventKey, strength, flashEnabled) 以命中事件时间与稳定 key 启动一次 0.26 秒的挤压回弹，前 0.095 秒允许叠加纹理闪亮。重复 key 不延长动作，暂停不消耗战斗时钟。建议 GameApp 传 recentHit.tick / tickHz，避免重建界面延后同一次命中的起点。普攻强度 1，手动技 1.5；角色自己的攻击变形也按角色区分。

自然完成同帧的最后伤害、死亡和到账仍被消费一次，转用 UI 时钟完成短尾巴。GameApp 自然进 cards 时提供 0.35 真实秒的无输入收尾，之后显示选卡；TextureEffects 放在选卡面板下面。恢复、切回、重播旧日志不产生新反馈。真正死亡才显示角色纹理缩小淡出与碎屑；漏怪、救场清除不冒充普通击杀。

到账飘字来自 stats.energyGained 的正差额，同帧多次到账合并显示一个真实总数，冷静波不产生普通能量图标或数字。setNumberStyle 回调复用 Typography 的真实数字字体，代码只负责描边与透明度。

## 可见性与约束

- 所有精灵和 Graphics 层共用原有最多 96 个槽、单配方最多 16 个槽的优先级池，新增代码图形也计入预算。高负载减少低优先级装饰；危险提示与技能启动优先。
- 战斗效果放入矩形遮罩，避开顶部 HUD 和底部技能/召唤控件；到账图标单独飞向真实能量 HUD 锚点。
- 区域纹理尺寸使用同一战场投影。粒子不是额外伤害区域，瞄准与射程仍由权威几何绘制。
- 画面晃动偏好关闭时，同时关闭命中强光层与纹理闪亮，保留轨迹、轮廓、音符、回弹及到账数字；没有普攻全屏泛白。
- B002 只作为视觉别名读取 B001 图和动作，角色着暖色，尺寸由 GameApp 决定；没有新增美术 ID。

## 验证

新增 vfx-feedback.test.ts 使用真实 Battle / GameSession 事件验证四大招一次启动及真实命中、末杀跨选卡 UI 尾巴、冷静期不虚报能量、减闪与单次回弹、补间不双倍缩时、慢动作音效及旧版暂停兼容。既有 VFX / 音频测试继续检查救场分支、恢复不重播、弹道重定向和池优先级。

这些自动检查证明事件与状态约束、代码 API 兼容；最终画面强度、遮罩和闪亮材质需在真实 Cocos Web 构建中目视验收。

首包实机复核后仅加强厨师对比度：黄色道路上原细线、四至七个透明小花难以形成视觉中心，改成暖白实心图形核心叠真实爆米花纹理。普攻核心约 106 逻辑像素、大招约 158，前半段保持实色再快速退场；外圈由密碎光改为四段厚线与四枚实心碎粒。普攻所有层最长仍 0.32 秒，大招仍 0.5 秒，真实脉冲次数和伤害均未变。其余三位英雄保持首包表现。
