# 全界面原稿复刻 v005

本轮按现行 14 张原稿覆盖全部游戏界面：N01–N06、S03/S04、D01–D06。N01 营地与 N02 收藏继承 v004 的原稿组件，其余页面重排到各自原稿布局。S01/S02 已被非战斗新版设计替代，不恢复旧入口。

## 制作与运行原则

固定艺术字、按钮轮廓、纸张、木牌、边饰从本工程原稿拆成独立组件；动态按钮使用同风格矢量底板。每个点击区域仍是原生 Cocos Button，不把整张截图覆盖在游戏上。

训练经验、等级、形态、阵容、波次、生命、能量、星级、技能、冷却、卡牌和结算都取自真实状态。样例数据先从底板中清除。F01 原稿特写可作为对应身份卡面，其他永久形态显示真实角色素材。局外升级与局内合成继续独立。

战场、结算、训练房和解锁空舞台用内置 imagegen 编辑本工程原稿：仅用指定场景区域，其他组件仍取原文件。战场不烘焙任何活动怪物、英雄、血条、弹道、技能或星级。提示词及编辑输出保存在制作包 `battle/source` 与 `outside`；清理区域和校验值记录到清单。七个手动技能图标从原预览提取纯插画，去掉旧缩略图内的标题、来源和冷却小字；金星从原结算卡面单独提取。

## 原稿之外的必要状态

失败结算使用同风格“再战一局！”艺术字，不展示胜利标题。空阵容位、未解锁技能、卡牌长文、技能第二页、形态解锁、瞄准确认、取消部署、旧局替换、脏草稿、广告待决、后台恢复和帮助使用相同材质与组件规则。它们有完整动态交互，但没有原稿对应状态，不宣称逐像素复刻。

原稿三排垫位置与实现中的左右交错站位存在差异。使用可逆的显示投影匹配道路与三排高度，保留 B 位在各道路右侧的拓扑。所有弹道、特效、范围轮廓和触点逆变换共同使用投影，不靠视觉移动人物破坏真实射程关系。

倍速、能量、救场与复活规则不变。原稿时钟样例不作为真实战斗时长；结算时钟来自累计模拟 tick。音乐不随战斗倍速加速。

## 验收交付

每页保存 450×800 与 360×640 的实际 Creator 运行截图，逐页与原稿对照；另验证辅助状态、缺字、资源加载、交互边界与保存事务。最终构建、校验和与结果写入 `docs/implementation/全界面原稿复刻-v005验收记录.md`，不沿用旧版测试数量。
