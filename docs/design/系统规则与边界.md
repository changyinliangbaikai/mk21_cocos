# 系统规则与边界

版本 v0.7 · 本文为详细系统规则的唯一源。用户确认与设计补充见[基线](设计基线与决策记录.md)。自动开波与布阵慢动作的实现边界见[本轮流程修订](自动开波与布阵慢动作-v007.md)；旧0.5/0.6局继续执行自己的完整快照。

## 1. 时间与2×

战斗逻辑使用统一战斗时间。1秒真实时间在1×对应1秒战斗时间，在2×对应2秒战斗时间。不是只改变播放动画，所有会影响战果的计时必须一起变化。

| 时间域 | 2×行为 |
|---|---|
| 刷怪间隔、怪物行走、投射物移动 | 同步加速2倍 |
| 英雄普攻、自动技能、玩家技能冷却 | 同步加速2倍 |
| 持续伤害间隔、减速/眩晕/护盾/基地保护时长 | 按同一战斗时间，真实时长减半 |
| 攻击前后摇、影响判定的动作事件 | 同步战斗时间；不能让动画与伤害事件各执行一次 |
| 怪物数量、基础生命、伤害单次值、能量值 | 不变 |
| 选卡、技能瞄准、设置、广告、后台暂停 | 战斗暂停；交互按真实时间，不压缩阅读时间 |
| v0.7防守中的召唤选位、移动/合成选位 | 0.2倍布阵慢动作，叠乘玩家1×/2×档位；放置成功或取消后恢复，查看射程不减速 |
| 首波布阵、免费复活准备 | 保持暂停，玩家确认后开始；不剥夺安全准备机会 |
| v0.7选卡后下一波倒计时 | 1.2真实秒后自动开波；设置、技能库、选位及后台会暂停倒计时，旧局仍手动开波 |
| 音乐、人声、非战斗按钮动效 | 保持真实时间；无变调 |

切换速度保留当前进度，不刷新冷却或刷怪队列。以“同种子、同战斗时刻的同操作”为对照，1×与2×应有相同怪物、伤害、能量和结果。人的操作时间不同可能带来战果差异，不能用此测试声称消除操作难度。

时长目标见节奏表：熟悉操作的标准流程可同时落入6～10和3～5分钟。UI选择、广告不会恰好减半，因此不承诺所有真实游玩记录严格为1/2。

## 2. 波次与奖励账本

一局预先确定20波敌人清单与基础能量预算。新局每波非Boss根怪完整收益至少80，Boss本体200；普通根怪每波+2（8到46）。v0.7在第5、10、15波各加入一只小Boss，第20波一只大Boss，Boss不会替换该波普通怪数量，具体账本见当前数值表。每个奖励有唯一归属，怪物只发生一次终态：击杀、漏出或救场清除。已终态怪物不得再次结算。

- 每波清单包含未出生队列。队列耗尽且所有已出生怪物终态后，判定波次结束。
- 分裂怪共享一个固定奖励预算：原型父体不给能量，子体分配预算。清除未分裂父体时直接结其剩余预算；父体已分裂时只结仍未结算的子体。总额不能重复。
- 漏怪扣基地耐久，移出战场，不给击杀能量。触发归零的漏怪已结算为漏出；救场不会给它重新补奖励。
- 同一逻辑步中基地归零与最后一个敌人结束，先处理失败状态；不能在0耐久下直接胜利。
- 波末卡牌与波号推进只发生一次。重复关闭弹窗、切后台或回调不能重复领卡。
- 第一波只需手动开始一次；第1～19波仍由玩家选择随机卡牌，选择后开始下一波1.2秒倒计时并自动防守。没有自动选卡，不增加波末领取按钮。自然末杀保留0.35真实秒视觉收尾再显示选卡，伤害、结算和奖励已经由同一事务完成。

记号：`R(w)`为第w波完整基础能量预算；`U(w)`为失败暂停时，本波仍存活和未刷出敌人的尚未结算基础能量。已击杀、已漏出及已领取部分不在U内。实际账本实现必须与此定义一致，不得读取另一版本新配置替换旧局预算。

## 3. 老爷爷事务

前提：本局老爷爷未使用，基地首次归零，战斗暂停。玩家可使用或直接结束本局；不使用不会跳过它取得第二阶段救场。

一次使用整体完成以下变化：

1. 标记老爷爷已使用。保留现有英雄、星级、卡牌、能量和技能冷却，不回档。
2. 恢复基地到最大耐久的50%（原型向上取整）。
3. 将本波所有存活及未刷出敌人清除，终止该波刷怪队列；未刷出怪以整波清除表现解决，不强制同帧实例化。
4. 增加`U(w)`能量；若w<20，再增加`R(w+1)`并设置冷静波为w+1。
5. w<20进入正常波末选卡；w=20直接胜利，预支为0，既无第21波也无冷静波。

清屏不触发英雄击杀连锁、召唤子怪或额外掉落；老爷爷的收益由上述账本一次结算。演出跳过不改变结果。清屏会处理首领剩余阶段的整体终态，不再补刷阶段怪物。

## 4. 下一波冷静期

冷静期严格覆盖预支对应的下一整波，到该波结束即解除，与抵扣多少能量无关。击杀、首领掉落、分裂子体及“击杀得能量”类加成在该波的能量收入均为0。原型不投放其它经济卡。

冷静期仍可花已有能量、召唤、合成、换位、释放技能、领取波末卡牌。第二救场的固定补给属于独立救援发放，照常获得；它不是怪物收入。

v0.6示例：第7波剩余U=30，第8波R=228，使用老爷爷立即加258。旧v0.5存档仍按它自己的R=46发76，不补差额。第8波怪物收入全部为0，无论实际击杀了多少；第8波正常或广告清屏结束都解除冷静。没有逐额欠款、利息或跨局结转。

## 5. 第二救场

前提：老爷爷已用、第二救场未用，再次基地归零。标题“我命由我不由天”。两按钮同大小同层级，展示完整差异。

| 项目 | 免费复活 | 自愿广告复活 |
|---|---|---|
| 消耗次数 | 第二救场1次 | 相同的第二救场1次 |
| 恢复基地 | 最大耐久50% | 相同 |
| 固定能量 | 80（原型2次召唤） | 相同 |
| 怪物与刷怪队列 | 保留当前状态 | 清本波全部剩余敌人及队列 |
| 清屏额外击杀能量 | 无清屏 | 不发；收益仅为固定补给 |
| 后续 | 原波继续 | 波末选卡或第20波胜利 |

免费路线：先发固定补给并保持战斗暂停，允许部署与合成，按“继续防守”恢复；接下来3个战斗秒基地不受伤害。怪物照常移动，保护期漏怪照常移出且无击杀收益。不重刷已漏怪，不清屏、不回血怪物、不刷新英雄技能。2×下保护真实时长1.5秒，但暂停部署不限速。

两分支再次失败均直接结算，不再出现任何复活广告。第二救场不新增冷静波；若当时处于老爷爷冷静波，原冷静规则继续，广告清完该波则结束冷静。

## 6. 广告结果与恢复

| 结果 | 处理 |
|---|---|
| 玩家选择免费 | 直接应用免费结果，不请求展示广告。 |
| 点击广告并获得完整观看凭据 | 一次应用广告结果。 |
| 玩家主动提前关闭、未达奖励条件 | 回到暂停选择页，可明确选择免费复活或结束；不自行清屏，不消耗复活次数。 |
| 未支持、无填充、加载或展示失败 | 按当前设计兑现已选择的广告结果作为异常兜底，标记fallback而非观看成功；不要求再看。 |
| 完成回调重复到达 | 以救场事务ID去重，不重复发能量、加血或推进波次。 |
| 免费结果已经确认后晚到广告回调 | 忽略，事务已终结，不能追加清屏。 |
| 关闭/后台导致结果未知 | 保持失败暂停态与待决事务，不超时偷偷开战；恢复时完成一次明确处理。 |

不让广告展示自动消耗机会；机会在实际应用某条复活结果时消耗。广告期间所有战斗与相关音频暂停，恢复时按原设置与游戏状态继续。等待未知回调时提供“改用免费复活”，确认后锁定该结果。

上述异常兜底为历史设计，曾参考[抖音广告运营规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/norms)及[抖音激励视频文档](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/open-ability/ad/incentive-ads)。2026-09-17 后按设计基线 D030 仅推进微信，抖音资料不作为当前平台要求；微信真实广告尚未接入，未来接入时需核对微信官方说明并完成真机验证。

## 7. 技能、合成与卡牌

- 每个英雄种类每局只解锁一次三星大招；同类多个三星共用该技能，不获得多个独立冷却。
- 本局已解锁技能进入库，2槽装备。非装备技能冷却也按战斗时间推进；换装保留冷却。
- 新解锁大招可立即释放；重复获得或换装不再次给“首次可用”。技能施放不可重复点击结算。
- 合成继承来源中较晚的下一次攻击可用时刻，不能靠拖拽或合成连续刷新普攻；升星后的行为在合法时刻开始，外观仍取本局形态快照。
- 任一合成同时校验种类、星级、实体存在和目标位置，一次性消耗两个副本生成一个。满格可通过把合法副本合入目标释放位置。
- 选卡三项生成并保存后，退出重进不重新随机；已选卡和波号推进整体保存。
- 卡牌三张候选全部有效且同页不重复。C010/C011/C012为不同的无限叠选通用牌，保障任意合法非空编队候选池始终至少3张；其余有限牌不达条件或满级则移出。详情见v0.5内容表和战斗参数。

## 8. 存档与中断

保存：局ID、随机种子、当前波及刷怪队列、怪物终态/位置/血量、英雄状态、能量、卡牌、技能库/冷却、基地耐久、倍速、冷静波、两次救场标志、当前UI阶段、待决广告事务。持久记录另存英雄解锁、永久等级、训练经验余额、已拥有/所选形态、编队、攻略累计与设置；局存档包含创建时英雄种类、等级、形态及配置快照。

救场、选卡、合成、波次推进必须完整保存，不可只保存到账能量而遗漏次数。退出不能恢复救场次数、改变卡牌、重复领取预支或清屏收益。存档暂只承诺本设备；云同步与跨平台同账号同步为后续独立范围。

所有状态机、收益幂等和实机中断恢复均属后续编码验收，本轮未实现。

## 9. 待部署与满员

3个待部署位已获用户确认。它们与场上9位共同容纳本局已召唤英雄，但待部署英雄不攻击、不提供光环，也不自动触发战场能力。

| 操作 | 结果 |
|---|---|
| 召唤后选择场上/待部署空位 | 成功占位才扣40能量；不会先扣钱再因满位失败 |
| 已有英雄拖到空位 | 移动，英雄身份、星级和下一可用时刻保留 |
| 拖到同名同星且未满三星的英雄 | 显示合成预览，合法松手后执行一次合成；松手前可移出取消 |
| 拖到其它已占位置 | 两个英雄交换，包括场上与待部署之间；最高三星之间也只交换 |
| 拖到非法区域 | 返回原位，不扣资源、不改变英雄 |
| 在待部署区合成 | 同样遵循2合1，结果留在目标待部署位；首次三星也解锁本局手动技能 |

已解锁玩家技能属于本局技能库，来源英雄放回待部署区仍可使用。待部署期间英雄的下一可攻击时刻按战斗时间经过，但不会积攒或补发攻击；换回场上后只能在合法时刻正常发起一次攻击，不刷新攻击节奏。下场前已经发射的弹道正常结算；尚未释放的攻击动作取消，下一可用时刻仍保留。

12位全满且没有合法合成是允许存在的阵容状态。例如4个种类各1星/2星/3星一只，共12只、28次召唤。此时仅禁止新增召唤，显示“阵容已满，可交换调整或继续防守”；开始下一波、选卡、换位、主动技能与救场照常可用。

救场固定能量与老爷爷能量照常到账，即使暂时无法花掉也不扣回、不强迫花完。原型不加入销毁、出售或额外付费扩容。若可玩性测试显示满员严重影响后期成长，再单独评估规则调整，不由实现临时补上退款系统。

## 10. 预告与操作记录

下一波预告从已固定的实际配置读取，包含主要怪物图标、出现路线、已有类型说明；可展开查看完整构成。指挥加速、分裂和快怪等信息应与实际类型对应，不显示虚假的必败提示。

第20波开始前显示首领预告，第20波完成后不出现第21波。冷静波将“本波怪物能量为0”放在预告中，救场固定补给不受此限制。

漏怪按波号、路线、怪物种类记录；技能使用记录本波施放次数和可用状态。失败/胜利回顾只报告观察事实，例如“右路漏过4只怪物”“本波玉米大爆炸未使用”，不把统计相关性写成必然失败原因。具体提示规则与新手引导见[体验补充](体验补充与新手引导.md)。

## 11. 局外永久养成

用户已确认永久等级提升数值并解锁形态与动画；局内1～3星合成独立。详细参数表与界面状态见[局外英雄养成方案](局外英雄养成与界面方案.md)，其中Lv1～5、每级5个百分点伤害、10/20/30/40经验成本、Lv3/Lv5解锁形态均为待实测建议。

- 每个合法完成的波次发1共享训练经验，以局ID＋波号仅入账一次。正常、老爷爷、广告清波同口径；免费复活本身不发；冷静波完成照常发。老爷爷不预支未来训练经验。1×/2×数量相同，未完成波不发，重玩新局可正常获得。
- 波完成与账户经验/已奖标志整体持久化。结算页仅显示已到账汇总；局存档回退不回退账户升级或重新发经验。攻略累计完成波数与经验余额独立，花经验不减少攻略进度。
- 升级整体校验并保存余额扣除、等级上升、形态解锁；重复点击不得重复消费。形态预览/穿戴不扣经验，未拥有形态不能穿戴。已拥有形态可自由选，换回旧外观仍享有当前等级数值。
- 自动伤害使用Lv1基值×永久等级倍率×星级倍率×适用局内加成。英雄K系技能继承对应英雄等级倍率，但不再乘星级倍率；P系技能不继承任何英雄等级。等级不改变控制时长、攻击频率或召唤费，不提前解锁K系技能。
- 新局创建时锁定英雄种类、等级、形态及配置快照；该局所有同类副本共用该快照。局外升级/编队/换装只在下一新局生效。现有存档继续原快照；开始新局需明确替换旧局。
- 形态与动画只影响表现，不额外产生命中、奖励或更改判定时间。局内星级用徽章/挂件/VFX区分，保持所选形态身份。所有Lv1的合理阵容仍应能完成标准20波，不设等级开局门槛。
