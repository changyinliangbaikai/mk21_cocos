# 体验补充与新手引导

版本v0.3。用户确认保留待部署区，并授权主动补充设计。以下是本轮补充的目的、取舍与交付要求；数值和效果仍须原型验证。

## 1. 补充原则

每个新增点至少解决一个具体问题：新玩家看不懂、玩家不知道为何失败、操作误触、状态边界无法继续、或爽感无法辨识。优先利用已有战场、英雄、卡牌与结算界面，不另加一套养成货币、每日打卡或复杂任务系统。

零充值、20波、两档速度、三星手动技能、两阶段救场与免费英雄解锁保持当前确认规则。提出可能改变这些核心体验的方案时，要说明变化；不凭“设计师经验”替代玩家测试。

## 2. 待部署区成为真正的备战空间

这是用户已认可的新增机制。已召唤英雄可以在3个位置中暂存、合成、与战场交换；待部署英雄不参与自动战斗，三星获得的玩家技能仍保留。详细操作表以[系统规则第9节](系统规则与边界.md#9-待部署与满员)为准。

备战位有浅色容器与“暂不上场”提示，和场上的绿色部署台区别明显。选中待部署英雄时，优先高亮合法空位和合成对象。只提示可能动作，不自动替玩家合成或花能量。

在满员时提示“阵容已满，可交换调整或继续防守”。4种英雄各1/2/3星恰好占满12位的情况真实可达，所以不能以“还有英雄未部署”为理由阻止开下一波，也不能要求先花掉救场补给。

取舍：需要留出一点屏幕面积，但能减少误召唤的挫败、增加调阵空间。首版保留3格，暂不增加扩容或出售系统。

## 3. 下一波预告让布阵有依据

选卡页底部与波间部署界面共用一条轻量预告：主要怪物图标、路线标记、至多一条主要特性提示，例如“轮滑香肠：移动较快”。展开可看完整组成，默认不把所有数据挤进HUD。

信息来自实际配置；玩家能提前认识快怪、护甲、分裂和指挥光环。第20波展示巨鹅预告。冷静波预告明确怪物能量为0，帮助玩家决定本波前如何花预支能量。

取舍：提前告知降低突然袭击的新鲜感，但让技能、站位和选卡成为可理解的决策。原型优先验证这种公平感，保留怪群出现时的演出惊喜。

## 4. 新手引导随操作发生

| 第一次遇到的事件 | 一次简短说明 | 不改变的内容 |
|---|---|---|
| 初始部署 | “选一名英雄，再点空位。” | 仍使用正常初始120能量，无独立教学货币 |
| 第一波获得能量 | 高亮能量与可召唤英雄：“打倒怪物，继续召唤。” | 不额外赠送隐藏能量 |
| 首次有同名同星配对 | 同步亮起两名英雄：“拖到一起，合成升星。” | 不强制合成，不改变技能或怪物 |
| 首次使用待部署区 | “这里的英雄暂不战斗，可换位或合成。” | 3格容量不变 |
| 首次三星 | 展示手动技能来源，提示装备与点击施放 | 不自动释放，不额外增加技能槽 |
| 首次进入冷静波 | “下波能量已预支，这波怪物不再给能量。” | 完整展示已有规则，无新增限制 |

触发条件以真实状态为准，不强制规定“第8波必须三星”。引导可跳过，已读状态在本设备保存；设置里可重新查看操作说明。2×引导文字按真实时间，必要的面板暂停遵循正常UI暂停规则。

不存在为了教程故意令玩家失败的必死波，也不强迫体验广告。熟练玩家跳过后直接按普通20波流程玩。

## 5. 操作容错和合成期待

召唤选位成功才消费；拖到非法区域原位返回；合成前展示目标星级与新增能力；三星解锁只提示一次。未解锁的大招在英雄详情里写明“达到三星获得”，帮助玩家知道投入后的结果。

技能瞄准暂停、取消不耗冷却、两技能槽与独立技能库沿用现有规则。战间换装提示来源与当前冷却；移动英雄不刷新技能。

以上复用已有组件，避免到处弹确认窗。关键操作预览清楚，普通交换一次完成，退出触控区域可取消。

## 6. 结算给玩家一个能理解的下一步

胜负结算展示本局到达波次、三星英雄、主要卡牌组合及至多两条回顾。首次失败和第二次失败的救场面板只可附一条短回顾，不遮挡救场选择。

回顾优先采用实际可验证信息，例如“本波右路漏过4只怪物”；技能提示只在该技能至少有一段战斗时间可用且整波未施放时显示“本波玉米大爆炸未使用”。若因刚解锁、冷却或未装备不可用，则不提示玩家遗漏。

建议用中性语气：“下次可以调整右路防御”“可以试试先减速，再集中爆破”。不宣称统计证明唯一失败原因，不把“去看广告”写成攻略建议。

## 7. 本轮对交付的影响

- 主规则新增待部署、满员、预告与操作记录边界；更新UI与编码验收。
- 美术先复用英雄头像、卡牌容器、合成高亮和结算面板，在原任务条目补充状态，无需批量增加素材。
- 本轮不生成新图片或音频，不修改主界面视觉候选，也不将其自动批准。
- 核心数值、20波怪物清单及两次救场机制不变；新增引导和预告的阅读时间纳入之后两档时长实测。
