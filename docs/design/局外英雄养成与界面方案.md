# 局外英雄养成与界面方案

设计准备 v0.5 · 当前会话仅做设计和视觉候选，不编写游戏代码。本文补充[设计基线](设计基线与决策记录.md)、[英雄设定](英雄怪物卡牌设定.md)与[界面方案](主要界面与预览方案.md)；用户最新明确要求优先。以下参数均未做数值或玩家实测。

## 1. 用户确认与设计建议

**用户已确认：** 局内通过合成升星；局外具有跨局保留的英雄养成，提升英雄等级与数值，并解锁不同形态及动画。这两条成长线同时存在。

**本轮设计建议，待实测或视觉确认：** 首版等级上限、经验来源与成本、伤害公式、形态解锁等级、具体形态名称，以及N01～N06界面结构。不得将这些建议写成用户逐项确认的参数。

| 概念 | 作用 | 保留方式 |
|---|---|---|
| 永久等级 Lv1～Lv5 | 提高英雄伤害，达到等级解锁形态 | 跨局保留；升级需要免费训练经验 |
| 局内星级 1～3星 | 同名同星2合1，改变局内能力；首次三星解锁对应K系手动技能 | 新局从一星召唤，星级与本局技能库重置 |
| 已拥有形态 | 改变外观及待机、攻击、胜利表现 | 永久拥有，局外自由选择；不额外增加数值 |

Lv3不等于三星，Lv5不代表五星。局外用“Lv”及等级数字，局内用星形徽章；形态栏使用名称及“Lv3解锁”等门槛标签，不画成另一组永久星级。全队Lv1的合理阵容仍应有能力完成标准20波，永久等级不作为关卡硬门槛。

## 2. 永久等级与升级消费

训练经验为全体英雄共享的免费资源，首版保存在本机玩家档案，由玩家决定投入哪位已解锁英雄。英雄解锁时为Lv1，不消耗经验；同名英雄无需重复解锁或收集副本。

| 升级 | 本次消耗训练经验 | 升级后相对Lv1的伤害加成 | 新增外观内容 |
|---|---:|---:|---|
| Lv1→Lv2 | 10 | +5% | 无新增形态 |
| Lv2→Lv3 | 20 | +10% | 解锁该英雄第二套形态及配套表现 |
| Lv3→Lv4 | 30 | +15% | 无新增形态 |
| Lv4→Lv5 | 40 | +20% | 解锁该英雄第三套形态及配套表现 |

每级增加相对Lv1的5个百分点，采用加法，不按1.05逐级复利。单英雄从Lv1升至Lv5合计消耗100训练经验。原型永久成长只调整伤害，不据此增加攻击速度、控制时长、射程或召唤费用。

N03升级示例：当前Lv2、经验余额48，按钮“升级至Lv3 · 消耗20”；成功后余额28、伤害加成从+5%变为+10%，并显示新形态已解锁。升级后由玩家选择是否穿戴新形态，不静默替换现有外观。

升级须校验英雄已解锁、当前等级、余额及上限，再整体保存扣经验、升等级和形态解锁。重复点击只执行一次。经验不足时说明缺额；Lv5显示“已满级”。不提供体力、充值经验、付费碎片、重复英雄卡或额外广告经验入口。

## 3. 训练经验入账与局内能量分账

每完成一波获得1训练经验，按合法的`WaveComplete`入账。完成20波合计20经验；在第8波失败且该波未完成，则保留前7波已到账的7经验。

| 情况 | 训练经验处理 |
|---|---|
| 正常完成、老爷爷清整波、广告清整波 | 同口径，每个实际完成的波次+1，整波只结算一次 |
| 免费复活但本波仍在进行 | 复活本身不发经验；之后完成该波才+1 |
| 老爷爷预支下一波能量 | 只预支能量，不提前发下一波训练经验 |
| 冷静波实际完成 | 仍+1；冷静期只关闭怪物能量产出 |
| 广告技术失败按设计兑现清波 | 若实际形成合法波完成事件，同样只+1；不按观看回调另发经验 |
| 未完成便失败、结束或放弃本局 | 不发未完成波经验；已到账部分保留 |
| 1×、2×、重玩新局 | 同一波奖励相同；合法新局可正常重复积累 |
| 离线及单纯暂停 | 不产生训练经验 |

局内能量仍用于本局召唤；训练经验用于局外升级，两者使用独立名称、图标与账本。经验已在波完成时永久到账，结算页仅汇总“本局获得训练经验”，不设第二次领取，不因返回大厅或重开再次加账。攻略累计完成波数独立于经验余额，升级消费不回退英雄解锁进度。

后续实现必须以稳定的“局ID＋波号”识别奖励事务，整体持久化账户入账、已奖记录和波次完成状态。恢复同一局、重复完成回调、重复进入结算或恢复较早局快照，均不得重领；已到账经验和升级消费记录不能随进行中局快照回退。正常重开生成新局ID，可再次积累。此处要求覆盖本机正常存档与恢复流程，未宣称已实现云同步或外部篡改防护。

## 4. 伤害与技能继承

设计建议使用下列计算关系，具体卡牌作用域、叠加及取整由后续配置明确：

- **英雄自动伤害**＝对应Lv1、一星基值×`[1＋0.05×(Lv－1)]`×局内星级倍率×相应局内伤害加成。当前一、二、三星倍率沿用1、2.1、4.4的原型值；不同自动效果使用各自基值，不重复套倍率。
- **英雄K系手动技能伤害**＝该技能基值×`[1＋0.05×(所属英雄Lv－1)]`×适用于该技能的卡牌加成。该基值已是三星解锁技能的独立数值，不再乘英雄星级倍率。
- **卡牌P系主动技能伤害**＝该技能基值×适用卡牌加成，不继承任意英雄的永久等级，也不取队伍最高等级。

等级不提前解锁K系技能。仍须在该局将对应英雄合成至三星，每类英雄每局只解锁一次；两个装备槽、技能库及换装保留冷却等现有规则不变。形态无独立伤害加成，选回Lv1外观仍享受当前永久等级的数值。

## 5. 新局快照与旧局继续

创建新局时锁定本局出战英雄种类、各英雄等级、所选形态及相关配置版本；同局召唤出的同类副本使用同一份等级和外观快照。星级变化仅改变局内能力与星级标识。

局外升级、换形态、调整编队在下一新局生效，不能即时改动正在进行中的局。已有局继续使用创建时快照，即使账户英雄后来从Lv2升至Lv3，继续旧局仍按Lv2计算。

N01有旧存档时主按钮为“继续防守”，显示旧局波次；局外配置旁提示“调整于新局生效”。“开始新局”需明确确认替换旧局，不能把进入编队误当放弃旧局。放弃未完局不会收回已经合法到账的训练经验。下一新局重置局内星级、能量、卡牌与救场机会，保留永久等级、经验余额和已解锁形态。

## 6. 形态命名与制作边界

下表全部为命名与美术方向建议，具体外形、动作和名称待用户确认。英雄业务名称与H编号保持稳定，形态名不是新增英雄。

| 英雄 | Lv1初始形态 | Lv3解锁形态 | Lv5解锁形态 | 必须保留的身份要素 |
|---|---|---|---|---|
| H001 爆米花厨师 | 见习厨师 | 爆米花主厨 | 玉米大亨 | 白色高帽、黄色围裙、爆米花及厨师身份 |
| H002 弹簧拳师 | 弹簧学徒 | 弹簧拳师 | 擂台拳王 | 弹簧身体、红色拳套、弹性出拳特征 |
| H003 电音青蛙 | 节拍新手 | 电音主唱 | 派对领队 | 绿色青蛙、音箱或耳机、节奏表现 |
| H004 拖鞋阿姨 | 邻家阿姨 | 拖鞋高手 | 街坊传奇 | 紫色卷发、粉色家居服、拖鞋武器 |

本次厨师养成图采用“见习厨师／爆米花主厨／玉米大亨”三档展示。每套形态都具备待机、攻击、胜利表现，可在挂件、表情及动作节奏上区分；差异只改变表现，不增加额外命中或改变战斗判定。

制作按每英雄共享骨架、基础动作与挂件复用规划。4英雄×3形态是12套外观方向，不扩成4英雄×3形态×3星的36套独立角色资产；星级以徽章、固定挂件或VFX区分，并保持所选形态身份。尚未解锁形态可预览，但不能穿戴。已有形态局外随时选择，当前旧局的外观仍遵循快照。

## 7. N01～N06界面流程

六张为独立视觉候选，状态为candidate/in_review；用户逐张确认后才可标记approved。不同图的余额、等级、阵容可以是独立示例，不伪装成同一存档连续操作；任何图都不代表已运行或已制作动画。

| ID | 画面与必要信息 | 主要入口及行为 |
|---|---|---|
| N01 营地 | 挑战入口、当前编队、收藏与养成入口；有旧局时显示波次与继续按钮 | 进入N02收藏或N04编队；继续旧局按快照，新开局按最新配置 |
| N02 收藏 | 仅当前4位真实英雄，显示拥有状态、永久Lv、定位；不混用局内星级 | 已拥有英雄进入N03；锁定英雄进入N05；提供N04编队入口 |
| N03 英雄养成 | 英雄Lv、当前形态、三档形态预览、加成变化、共享经验余额及升级成本 | “升级至LvX”执行升级；“查看解锁内容”独立查看形态及动作；已拥有形态另设穿戴操作 |
| N04 编队 | 最多4个英雄种类，展示永久Lv和所选形态，未拥有英雄不可编入 | 确认保存下一新局编队并返回营地；不改变旧局、不自动开战 |
| N05 锁定英雄 | 英雄能力及形态预览、明确的攻略解锁条件和当前进度 | 沿用H004累计完成10波或游戏内夸作者解锁；夸赞进入D05，不能升级未拥有英雄 |
| N06 解锁成功 | 指定英雄名称、Lv1初始形态、“已永久解锁”及下一步 | “查看养成”进入N03，或进入N04编队；不会赠送三星、满级或K系技能 |

典型路径：`N01→N02→N03`完成养成；`N01→N04→N01→开始新局`应用编队；`N02→N05→D05夸作者→N06→N03/N04`完成提前解锁。正常攻略达成条件后也进入同一个N06，不消耗训练经验。

升级按钮与解锁内容详情必须分离：点击形态缩略图仅预览，点击“Lv3解锁内容”只看说明，均不扣经验；只有明确标明目标等级与成本的升级按钮才提交消费。新形态解锁后可展示结果并提供穿戴选择，不把“预览”“升级”“穿戴”做成同一个含糊按钮。

当前只有4位英雄，最多选4确实缺少完整的队伍取舍。先让N04承担编队确认与新局配置；用户已采纳原型先4英雄；未来“至少6选4”作为内容扩展建议在验证后另行讨论，不在本轮画出不存在的第5、6位英雄，也不据此扩大首版上线范围。

## 8. 后续交接与验证重点

- 全局文档应补充永久等级、训练经验和形态；原“局外只有英雄解锁与设置”的描述不再完整，原局内经济与合成机制继续有效。
- 结算保留“局内星级与技能新局重置”，同时明确“永久等级与已拥有形态保留”；训练经验显示已到账汇总。
- 原英雄伤害表按Lv1口径解释；原20波目标仍需在Lv1验证可完成，不能把刷等级设为强制补洞手段。
- 后续验证升级一次扣款、经验一次入账、冷静波经验不受影响、老爷爷不预支经验、旧局快照不变，以及三星与Lv3技能语义分离。
- 单英雄满级需100经验的节奏、等级伤害增益、形态吸引力与12套外观的实际制作成本均待验证。本轮未完成数值实测、动画制作或编码验收。
