# 设计基线与决策记录

版本 v0.7 · 2026-09-13。D012–D019保留当时设计阶段的工作范围；用户后续已授权素材制作、MVP接入、视觉还原和试玩修复，当前按D020–D029及本轮连续战斗、Boss与特效修订执行。

## 1. 使用规则

“用户确认”是当前产品约束；“设计补充”是为避免后续编码猜测而提出的默认方案；“待实测”表示数值或体验尚未验证。设计补充允许后续设计讨论调整，不应冒充用户逐项指定。

文档冲突处理顺序：用户最新明确要求 → 本文件确认项 → [系统规则与边界](系统规则与边界.md) → [玩法说明书](游戏玩法设计说明书.md) → 内容与素材规格。发现冲突先修文档，不在代码里悄悄选择另一种规则。

D016（用户追加授权）：由设计师主导后续设计，用户负责决策与补充；先划分主要界面并分别生成预览供确认。当前提出4个主界面＋6个关键弹窗，均待逐张确认；本轮图片授权扩展了D013的单张范围，继续不编写游戏代码。见[主要界面与预览方案](主要界面与预览方案.md)。

D017（用户确认）：加入轻量永久养成，攻略获得免费经验，局外提升英雄等级与数值；战斗局内仍通过合成升星。

D018（用户补充确认）：局外升级还解锁不同英雄形态与动画。本次明确将等级、数值、形态与动作展示纳入独立养成页，不把局外等级与局内星级混用。

D019（用户采纳）：接受原型先4英雄、1张20波地图、保留完整局内外循环；补战场初始参数、验证第一局节奏、以通关和形态收集作为首版目标、先做一名英雄形态/动画小样再批量生产。更多英雄与章节在验证后扩展。用户要求补齐编码前准备并提供独立编码会话提示词；本会话不开始编码、不自动创建新会话。

D020（后续用户授权）：制作全部美术与音乐并接入可玩MVP，允许本地去底、裁切、缩放与打包；此前“只做设计”范围不再约束这些已明确授权的工作。

D021（后续用户要求）：全部有效界面按此前预览还原，尤其固定艺术字、按钮、卡框和场景。v005覆盖14个界面，实际资源与视觉验证见对应实施记录。

D022（本轮用户试玩反馈）：怪物沿全程保持恒定自然移动速度；越过英雄后仍应能被攻击；选中已部署英雄时展示虚线攻击范围。英雄仍需满足各自真实射程，技能减速等明确效果保留。

D023（本轮用户试玩要求）：每波普通怪完整击杀至少可获得80能量，Boss本体200能量，每波怪物数量逐步增加。救场次数、预支冷静和40能量召唤不变。

D024（v0.7用户要求）：四位数能量仍需有足够右留白，不缩窄数字；波次提示数字与中文协调排版，尤其双位数不挤压。

D025（v0.7用户要求）：开始后不逐波要求手动开战，后续自动下一波；选择英雄卡准备放置时进入布阵慢动作，放置后恢复原速度。

D026（v0.7用户要求）：强化普攻与三星手动技能的打击特效，使四英雄的攻击表现明显不同，打击爽感作为重点验收内容。

D027（v0.7用户要求）：每5波出现一个Boss；5、10、15为小Boss，20为大Boss。

D028（v0.7用户要求）：适当缩小战场英雄，改善与怪物的大小关系。

D029（v0.7用户判断）：MVP玩法设计已认可，本轮围绕以上体验优化推进，不追加付费、系统扩张或新的局外养成。

## 4. 已被新要求替代

- 旧“10波”调整为20波。
- 旧“完全无广告”调整为零充值、一次自愿激励广告分支，免费复活继续可用。
- 旧“老爷爷回到本波开战前”取消；当前为直接清整波，不回档。
- 旧“逐点抵扣预支额直到还完”取消；当前为下一整波关闭怪物能量收入，波末恢复。
- 已否决的弹球方案不属于本项目设计。

## 6. v0.5编码准备口径

[首版范围与试玩验收](首版范围与试玩验收.md)定义A战斗雏形、B完整可玩循环、C素材与双平台交付；独立编码任务以完成P0～P5的B为目标，不能把仅建目录/纯逻辑测试或P2雏形当作完整交付。原型使用占位资源，真人试玩和实际平台结果单独标记，不由图片替代。

A017设计补充：C010/C011/C012作为三张不同的无叠选上限通用牌，仍保持15张总数，保证任意合法1～4英雄编队都能完成19次三选一。C010改为普攻周期×0.97^层数；C011改为射程每层+5%；C012保持自动伤害每层+10%。C002明确低星直接伤害+8%的有效补偿。旧C010减速目标伤害卡和旧C011范围伤害卡由此版本替代，H003易伤与C009击退碰撞仍提供组合空间。

A018设计补充：地图坐标、速度、射程、控制/连锁上限、技能事件和卡牌作用域按[战斗参数](战斗空间与判定参数.md)与JSON执行；数值可以通过原型实测配置化调整，必须记录原因。它们是开工初值，非用户逐项确认或已平衡的结果。

A019（v0.6实现选择）：普通根怪从8只开始每波+2，第20波46只普通怪另加Boss；保留特殊怪出场阶段与数量，新增数量使用M001，不额外提高HP或速度。各怪物奖励和分裂共享预算见[数值表](数值与20波节奏表.md)。具体曲线仍需真人试玩。

A020（v0.6交互选择）：单击部署英雄独立查看范围，战斗继续；换点英雄切换查看，点空白/同英雄取消。保留拖拽，并增加明确的“移动英雄”按钮进入原有选位模式。旧局保持完整0.5配置和账本，新局使用0.6；营地显示生效提示，不静默重置玩家进度。

A021（v0.7默认实现）：首波和免费复活仍手动准备；选卡后1.2真实秒自动下一波，0.2布阵慢动作叠乘当前1×/2×，移动/合成与召唤使用同一时钟，射程查看不减速。老0.5/0.6局保留原时钟与波表，0.7新局启用新流程。

A022（v0.7默认实现）：战场英雄从154×160缩为118×126，触控区保持余量；小Boss为复用巨鹅造型的暖色“小鹅先锋”，5/10/15波生命320/480/720，四个Boss本体均200奖励。普通怪生命与伤害不因本轮额外提高。

A023（v0.7表现补充）：自然末杀预留0.35真实秒收尾再呈现选卡；特效按真实事件播放，命中闪亮/挤压回弹、各英雄独立轨迹与爆点、三星大招多阶段演出均不改变伤害判定。减少晃动偏好同时降低强闪，保留核心轨迹。
