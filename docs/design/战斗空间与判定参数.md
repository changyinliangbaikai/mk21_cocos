# 战斗空间与判定参数

版本 v0.7。新增三次小Boss，保留所有既有普通怪HP、速度与逐波构成。它是设计资料，不是游戏实现或平衡实测结果；用户确认的次数、20波、零充值、升星/等级分离等约束见[设计基线](设计基线与决策记录.md)。与本文配套的[参数JSON](configs/prototype-v0.5.json)保存具体数字，[固定种子刷怪样例](configs/wave-spawns-seed-20260912-v0.5.csv)用于实现对照。

## 1. 坐标、路线与部署

采用720×1280竖屏设计坐标。战场是独立720×680逻辑空间，原点在战场左上，x向右、y向下；参考画布中战场原点在(0,120)。界面可按安全区平移/等比缩放，世界坐标、射程和速度不能因屏幕尺寸变化。下部召唤、技能及待部署UI不在怪物世界中。

- 三路中心x分别140、360、580，道路宽56。怪物出生y=32，防线y=648，路径长616。横向路线不互相切换；同路怪物不碰撞、不堵路，英雄不阻路。
- 九个英雄位：L1-A(70,180)、L1-B(210,350)、L1-C(70,520)；L2-A(290,180)、L2-B(430,350)、L2-C(290,520)；L3-A(510,180)、L3-B(650,350)、L3-C(510,520)。每位中心距所属道路70，部署圆半径30；所有英雄中心均在道路外。主预览只作画风参考，不反推配置。
- 三个待部署位R1/R2/R3属于UI槽，无战场坐标和自动索敌。位置提示与星级可见；其行为遵循系统规则。
- 射程按英雄中心至怪物中心的欧氏距离判定，边界包含等于。伤害范围、胶囊宽度按怪物中心判定；怪物身体半径用于显示，C009碰撞另用32单位中心接触阈值，不暗中扩大射程。
- 路线用于移动和路线技能选择；除明确只作用选定路的技能外，范围与索敌可跨路。九个场上槽是固定位置，不允许任意拖到道路。

## 2. 时间、事件与目标选择

战斗固定步长建议1/60战斗秒。配置秒数转换为tick时向上取整，刷怪样例指定的tick直接使用。1×/2×只改变真实时间积累速度，输入记录使用战斗tick；后台、选卡、瞄准、布阵及其它暂停不累计待补战斗时长。前台低帧可分帧追赶，不删怪、不丢伤害来追时间。

每步顺序固定：到期状态清理→合法输入命令→到时刷怪→到时攻击/弹道/技能脉冲→伤害与死亡派生队列→怪物行为与位移→漏怪扣耐久→失败优先/波完成判定。死亡派生在当前步以先进先出队列处理；单怪只有一次终态，救场清屏不进入普通死亡派生。控制抵抗、吸血/掉落等未配置机制不自行增加。

状态有效区间为[startTick, endTick)，到达endTick的该步先移除状态，再处理任何命中。硬控结束时在该步先建立对应免疫窗口；免疫自身到期后该步可重新施加硬控。H003同次音波先对各存活目标施加减速/易伤/适用硬控，再结算伤害，所以本次命中即享受新易伤；Lv1二星无其它增益、无护甲时首击为8×2.1×1.15=19.32。死亡后的控制操作忽略。

所有实体有单调递增稳定ID。默认索敌按“距防线剩余路径最短→实体ID小”排序；H004先挑精英/Boss，再按上述规则。怪物离开射程后已释放的锁定攻击可继续；未释放前目标消失则本次攻击取消并正常进入下一攻击时间，不即时重打。没有目标时保持就绪，不空耗攻击周期。

攻击周期从本次启动时记录下一启动tick；前摇占在该周期内，不另加到周期之后。首次召唤就绪，但第一击仍经历前摇。移动/交换不刷新周期；前摇中移动取消本次未释放攻击并保留周期。合成取两来源较晚的下一可攻击时刻；计数型被动重置为0，不能触发免费蓄力拳/追加追击。波间保持攻击、技能冷却与计数；新局清零。

生命与伤害用数字存储；每个最终伤害事件按四舍五入至4位小数（半值向上），生命≤0立即进入唯一死亡终态。显示值可取整但不能反向影响判定。负伤害禁用；0伤害控制技能不凭空补1点伤害。

玉米标记同一目标只保留一份：可连爆优先，再取较高爆伤，同级取较小来源ID；较弱覆盖仅延长存续到两者较晚时间，不降低强度。死亡仅触发一次标记爆炸；连锁深度最多8（起始死亡为第1层），每次爆炸伤害携带原链ID与深度，第8层伤害可击杀但不再植入新标记，且由第8层致死的目标即使已有标记也不再爆炸。较早层击杀带有另一来源标记的目标时，下一爆炸继承当前链ID与深度+1，不因标记来源变化重置深度。标记存其来源类别（自动/K001）、等级、卡牌层数与伤害快照，来源移动或合成不会回溯改变它。二星标记本身只作能力预告；C002的直接普攻补偿让低星选卡仍有效。

分裂父体死亡先生成三子体再执行该死亡的标记爆炸；子体可被同次爆炸击中，仍共享原父体12能量预算（3子体各4，父正常死亡0）。救场清除不分裂、不连爆、不触发C009。

击退沿原路向出生端立即改变逻辑进度，最大退到出生线，不跨路；实际距离按抵抗、间隔、单次/滚动预算和地图边界共同裁定。视觉用短插值表示，逻辑不等待插值结束。滚动预算只计实际位移，零位移不制造碰撞。抵抗不等于免疫；Boss可被救场清除，救场不走控制抵抗。

原始HP保留，v0.7奖励以当前内容表和JSON为准；普通根怪HP乘第1–5/6–10/11–15/16–20波1.0/1.1/1.2/1.3，分裂子体继承该波倍率；大Boss使用1400独立HP，小Boss读取`hp_by_wave`的320/480/720，不重复乘分段倍率。物理类包括H002/H004、K002/K004、P001和C009；H001/H003、K001/K003/P002为能量伤害，P003无伤害。除M002外原型不设护甲，不追加暴击、闪避或元素克制。

候选池由未达有限上限且符合带入/已解锁条件的所有卡组成，按ID排序后用独立卡牌随机流等权无放回抽3张。C010/11/12始终有效，池至少3；保存三张结果后才显示，选择一张原子保存并关闭，重进不重抽。卡牌有效性按本局带入英雄种类及技能库判断，不因暂时没部署该英雄或把英雄放到待部署而撤销卡。尚未解锁的K技能相关附加效果必须在卡面展开说明，不宣称已经可释放。

## 7. 刷怪样例与随机流

v0.7每波普通根怪8→46、逐波+2，第5/10/15各加B002，第20波加B001；共544根怪、最多69个分裂子体，完整基础能量6386（非Boss5586+四Boss800）；目标战斗秒合计400，不是强制到时清波。运行种子为无符号32位非零整数，样例20260912。

每波独立种子=(局种子 XOR 波号×2654435769的低32位)，若为0则用1831565813。展开该波普通根怪类型（不含Boss），采用xorshift32（左移13、无符号右移17、左移5，每步只保留32位）与Fisher–Yates从末向前交换，交换索引=nextUint32模(i+1)。路线按打乱后的普通根怪索引i及波种子模3循环分配：(i+phase)模3+1。首领固定L2。

普通刷怪窗口tick=roundHalfUp(目标战斗秒×0.60×60)，n只普通根怪第i只tick=roundHalfUp(i×窗口/(n−1))；n=1时在0tick。Boss在窗口的65%处生成，和普通怪不互相替换。排序按tick→普通先/Boss后→原序，赋予波内顺序ID。样例CSV只列根怪，不预先实例化子体。路线、间隔、生命、奖励在1×/2×使用同一个清单。

卡牌使用另一随机流，初始为局种子XOR2779096485，零种子仍采用上述回退值；与刷怪流完全独立。每次选卡按同样洗牌算法从ID排序池取前3，保存随机流后状态和候选。既不能因多播放一次动画消耗随机数，也不能因为两档帧数不同改变波表。
