# 界面交互说明

版本 v0.7，竖屏720×1280逻辑尺寸；实际按安全区适配。界面沿用v005原稿组件和v006射程查看，本轮扩宽能量框、重排波次艺术字、缩小战场英雄并加入[连续战斗与布阵慢动作](自动开波与布阵慢动作-v007.md)。

## 1. 页面与状态

当前为6个主界面＋7个关键浮层，另展示锁定英雄详情状态，共14种代表画面，见[主要界面与预览方案](主要界面与预览方案.md)。英雄收藏、英雄养成、出战编队分为独立页面；初始部署、战间部署复用战斗页。流程为大厅→编队（可选）→初始部署→战斗→波末选卡→战间部署→下一波；分支包括技能库、技能瞄准、老爷爷、第二复活、胜负结算。恢复一局时返回保存的阶段，不能总是回到可重复领奖的入口。

## 2. 战斗布局

```text
┌─────────────────────────────┐
│ 基地20/20  波次08/20  [1×] [暂停] │
│ 能量160  冷静状态（仅有效时显示）  │
├─────────────────────────────┤
│ 入口一       入口二       入口三 │
│  路线/英雄位    路线/英雄位      │
│       可读的怪物、技能与弹道      │
│  英雄位       英雄位      英雄位 │
│──────────基地防线──────────│
├─────────────────────────────┤
│ [手动技能A] [手动技能B] [技能库] │
│ [H001 40] [H002 40] [H003 40] ...│
│ 待部署位×3 / 合成与目标提示       │

```

核心点击目标在小屏仍有足够触控范围；重要按钮不被能量飘字和技能特效覆盖。战场技能层、敌人层、英雄层、HUD分清优先级。怪物危险读数优先于装饰。

## 3. 召唤与合成

点击底部英雄召唤卡后高亮可用空位，选位完成才扣能量；没有空位展示“先合成或调整位置”，不发起扣款。可将待部署英雄放入场上或进行合成。拖到非法区域返回原位；只有同名同星且未满三星的配对出现合成预览，其余合法占位目标执行交换。

单击场上英雄显示包含卡牌增益的虚线攻击范围，不暂停战斗；单击另一英雄换选，点同一英雄、战场空白或取消按钮关闭查看。已选英雄可直接拖拽，也可点“移动英雄”进入点击选位模式；取消选位后仍可查看范围。候补区没有战场射程，召唤、瞄准、切页或阶段结束会清除查看。英雄头部与身体都属于可点击区域。

待部署区固定3格，显示“暂不上场”的低调提示。拖到空位移动；拖到同名同星且未满三星的对象上预览合成；其它合法占位目标执行交换。没有合法合成且12格全满时，文案改为“阵容已满，可交换调整或继续防守”，开始下一波与救场后的继续按钮照常可用。详见[系统规则第9节](系统规则与边界.md#9-待部署与满员)。

合法合成预览展示升星与新增效果。三星首次出现技能解锁小卡；空槽提供“装备”，满槽显示“已收入技能库，波间可替换”。多次三星不重复弹解锁、不打断战斗。

## 4. 手动技能

可用时按钮有明确亮态，冷却显示倒计时。点按进入瞄准暂停，目标确认后恢复原倍速；取消不耗冷却。世界时间暂停时，既不恢复技能冷却也不继续出怪。

技能库展示已解锁全部技能。装备槽只在战间允许交换；未装备技能仍记录其战斗冷却。技能来源图标区分“英雄三星”和“卡牌”。技能库、选卡页可查看简洁说明。

## 5. 选卡

三张同规格且有效、不重复的卡，显示作用英雄、当前等级、明确效果。可长按或展开查看详情；不以阅读倒计时强迫选择。选择后进入可调整阵容状态，提供“开始下一波”。已选记录先保存再转场。

选卡页显示下一波主要怪物与路线，可展开查看完整构成。第5、10、15波显示小首领，第20波显示大首领，冷静波说明怪物能量为0；不自动选择卡牌。v0.7选择卡牌后自动倒数1.2秒进入下一波，倒数条无须点击；此时可选择召唤、移动或技能库，操作期间倒计时暂停。首波/免费复活仍保留手动开始按钮。

战斗中召唤选位和移动选位使用0.2倍慢动作（叠乘当前1×/2×），顶部显示“布阵慢动作”，完成或取消后恢复。选中英雄查看射程保持正常防守。战场英雄图像由154×160调整为118×126逻辑像素，点击区域仍覆盖头部与身体并保留余量，候补、收藏和养成的角色比例保持原页面设计。

局内能量徽章保留原闪电与圆角，仅拉伸空白中段至250原稿像素；数字区163像素，右侧留20像素，支持四位及更长数字。选卡标题按“第＋数字＋波守住了！”整体居中，单双位数字都有自然宽度，禁止仅横向缩放数字。

第20波直接胜利。正常波末与清屏波末使用同一奖励入口，避免重复领取。

## 6. 老爷爷

首次失败冻结战场。按钮显示“召唤老爷爷 · 本局1次”，摘要动态显示“清本波，获得剩余怪物能量+下一波预支；下一波怪物能量为0”。第20波改为“清本波并通关”，隐藏不存在的预支。

确认后演出、恢复、发能量、清屏对应一次结果。跳过仅省演出。冷静波HUD固定显示“本波怪物能量为0 · 波末恢复”，救场固定补给仍可获得；不可出现按秒倒数或按余额还款的旧UI。

## 7. 我命由我不由天

```text
            我命由我不由天
          本局最后一次复活机会
       两种方式均恢复10耐久、获得80能量

 [直接复活]                 [看广告复活 ▶]
 保留本波怪物               额外清除本波怪物

                 [结束本局]
```

数值从配置展示而非写死。两按钮同尺寸、同级对比度且位置稳定。广告按钮使用平台要求的明确标识。任何选项都不提前勾选；普通复活不能惯性误触广告。

免费后给部署暂停，再点“继续防守”。广告取消/失败/重复回调等交互严格采用[系统规则第6节](系统规则与边界.md#6-广告结果与恢复)，本页不另定义发奖策略。

## 8. 图鉴与设置

图鉴展示已解锁与未解锁英雄、能力预览、正常攻略条件、游戏内夸作者入口。夸赞只选择原创台词即可，立即显示永久解锁结果；可提前解锁全部英雄。

设置支持音乐、音效、语音分别调整，震动与屏幕晃动开关，倍速状态记忆。静音时所有危险、冷静期与技能可用状态仍有视觉提示。2×按钮只在1×与2×切换，战斗继续而无重复动画判定。

## 9. 引导与结果回顾

按首次真实事件显示一条短提示，可跳过；在设置中保留操作说明入口。合成配对使用同形高亮而不自动合成；三星说明技能归属，待部署说明不上场。详细触发条件见[体验补充](体验补充与新手引导.md)。

结果页给至多两条基于实际记录的回顾；救场页最多一条且不遮选择。可显示漏怪主要路线及本波可用但未使用的技能。没有统计时不编造原因，刚解锁或全程冷却的技能不提示“未使用”。

## 10. 局外升级、形态与编队

N01营地→N02收藏→N03养成；锁定英雄进入N05详情，攻略或夸作者达成后显示N06解锁结果。N04只配置下一新局的可召唤英雄种类，不负责战场站位。养成页明确Lv、训练经验及成本，升级前后数值对比和解锁外形；切换预览、升级、穿戴各为独立操作。动作预览对应所选形态，未制作的静态图不能冒充动画。继续旧局旁提示养成调整于新局生效。详细页面见[局外养成方案](局外英雄养成与界面方案.md)。

结算页显示本局已到账训练经验，并写明永久等级/形态保留，局内星级/技能重置；不新增领取按钮。旧S04图尚待补这些字段。

编码交互按[界面状态与操作契约](界面状态与操作契约.md)处理，包括升级/形态、编队草稿、空队、未保存退出、首个技能空槽装备、战中技能库只读和旧局保护。
