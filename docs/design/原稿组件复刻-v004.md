# 原稿组件复刻 v004

依据：用户再次指出v003与原预览差距明显，要求充分使用SVG或其它方法，目标是与原稿一致。本轮的制作基准是本项目N01营地、N02收藏、N03养成、N04编队原图，优先完整重建营地与收藏的几何布局；其余页面先接入各自原稿标题与按钮资产。

## 关键改变

此前用共用木牌、字体和手工皮肤近似不同原稿，无法保留原标题不规则字形、按钮厚度和人物构图。v004把固定图形作为原稿组件处理：保留源像素及宽高比，再把动态数字和状态拆成原生UI节点。

| 要素 | 实施方式 |
|---|---|
| 固定标题 | 每页分别提取完整原稿标题牌，停止重新排字 |
| 固定按钮与导航 | 原图透明切片；使用SIMPLE Sprite等比呈现；原生Button保持语义与点击 |
| 动态按钮 | 真正SVG路径底板，透明PNG进入Cocos；动态文字独立，不把字形拉伸 |
| 场景与版式 | N01/N02原稿环境拆出组件区域，再按941×1672参考坐标重建独立UI节点 |
| 收藏卡 | 默认形态用原稿近景卡、原始名字与定位胶囊；锁定/拥有进度实时显示 |
| 真实进度 | 经验、等级、阵容、解锁数均来自存档；移除原稿示例值 |
| 未出现状态 | 高级形态、拥有阿姨、继续、禁用、按下明确作为原稿风格的延展状态 |

SVG是生产方式之一，不会自动还原复杂手绘原稿。能够直接保留的固定像素不再重画；需要变化的图形才制作矢量母版。主CTA从原来的宽扁条恢复为原稿约474×163的短厚胶囊，去掉原稿没有的播放三角形。

## 交付与验收

[制作包](../../assets/art/production/mvp-v1/reference-ui-v004/README.md)包含43个原稿组件与环境、12个矢量底板状态；[原稿差距评审](../reviews/UI原稿复刻评审-v004.md)明确位置、比例、字形和材质要求。

逐项确认：源图和裁切可追溯；不透明原始像素不被改写；固定控件不非等比拉伸；450×800及360×640运行位置与原稿对齐；按下松手、原生点击和动态状态真实；截图来自实际Creator游戏。完整图像对照及差分需要排除示例数值差异，不能为追求相似度覆盖真实存档。

本轮已在最终真实Creator构建中完成营地/收藏对照，固定标题、主按钮、导航、卡片近景和版式按原稿保留。底栏贴片硬边、进度圆头及高级形态残留默认帽沿的问题均已修复；真实升级、穿戴、免费解锁和继续/新局流程通过。对照见[营地](../../assets/art/production/mvp-v1/reference-ui-v004/reviews/original-vs-runtime-camp.jpg)、[收藏](../../assets/art/production/mvp-v1/reference-ui-v004/reviews/original-vs-runtime-collection.jpg)，构建及交互范围见[专项验收](../implementation/原稿组件复刻-v004验收记录.md)。

“完全一致”是验收目标，不是对所有页面的预先结论。静态原稿没有所有等级、解锁和按下状态，也没有遮挡处的原始图层；新增状态与待复刻页面分别记录。仅按钮或标题通过不代表整页已达到目标。
